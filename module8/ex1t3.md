# Exercise 1, Task 3: Use Copilot in Excel to analyze communication metrics

As the Communications Manager at Boulder Innovations, one of your responsibilities is evaluating the effectiveness of internal communications. The Senior Leadership Team (SLT) has requested a summary of employee engagement with the company’s quarterly newsletter. To support this request, you'll use Microsoft 365 Copilot in Excel to analyze newsletter engagement data, identify trends, highlight high- and low-performing departments, and generate executive-ready insights.

In this task, you use Copilot in Excel to analyze newsletter open rates and click-through rates, create visualizations, identify engagement patterns, and generate recommendations that can help improve future communication strategies.

### Task 3.1: Open the newsletter engagement workbook

1. In Microsoft 365, select **Apps** from the navigation pane and then select **OneDrive**.

1. Navigate to **OneDrive**, locate the **Boulder Q4 Newsletter Click Rates.xlsx** file, and then open the file in **Excel for the web**.

   ![](../media/ms4004-l8-9.png) 

5. From the Excel workbook, select the **Copilot** icon located at the bottom-right corner of the screen to open the Copilot pane. In the Copilot pane, leave the response mode selector set to **Auto**. Then verify the **Allow editing (1)** icon appears in the prompt field next to the plus (+) sign. 

    ![](../media/ms4004-l8-10.png) 

### Task 3.2: Analyze newsletter engagement trends

1. In the Copilot pane, enter a prompt asking Copilot to:

   * Summarize engagement trends in the workbook.
   * Compare each department against the overall average.
   * Identify departments with below-average engagement.
   * Display the results in a new worksheet.

   Example prompt:

   ```text
   Analyze the newsletter engagement data in this workbook. Identify overall trends, compare each department's performance to the overall average, and highlight departments with below-average engagement. Display the results in a new worksheet.
   ```

2. Review the analysis generated by Copilot.

   ![](../media/ms4004-l8-11.png) 

3. Examine the departments identified as having below-average engagement.

### Task 3.3: Create a communication engagement visualization

1. Return to **Sheet1**.

2. In the Copilot pane, enter a prompt requesting a chart that compares departmental engagement metrics.

   Example prompt:

   ```text
   Create a bar chart comparing open rates and click-through rates by department and display the chart in a new worksheet.
   ```

3. Review the chart created by Copilot.

   ![](../media/ms4004-l8-12.png) 

4. Identify any departments that significantly outperform or underperform others.

### Task 3.4: Identify top and bottom performing departments

1. Return to **Sheet1**.

2. Ask Copilot to rank departments based on click-through rate.

   Example prompt:

   ```text
   Rank all departments by click-through rate. Highlight the top three performing departments and the bottom three performing departments. Display the results in a new worksheet.
   ```

3. Review the ranking generated by Copilot.

4. Note any departments that may require additional communication support or targeted engagement initiatives.

### Task 3.5: Generate an executive summary

1. Return to **Sheet1**.

2. Ask Copilot to create a concise executive summary of the communication metrics.

   Example prompt:

   ```text
   Create an executive summary of this newsletter engagement data. Include the average open rate, average click-through rate, departments with below-average engagement, and recommendations for improving engagement in lower-performing departments. Display the summary in a new worksheet.
   ```

3. Review the summary generated by Copilot.

4. Verify that the summary includes:

   * Overall engagement metrics.
   * Below-average departments.
   * Recommended improvement actions.

### Task 3.6: Refine the executive briefing

1. Ask Copilot to suggest additional insights that could improve the executive briefing.

   Example prompt:

   ```text
   Review this analysis and suggest any additional information that would improve an executive briefing. Prioritize each recommendation as High, Medium, or Low priority. Do not make any changes automatically.
   ```

2. Review Copilot’s recommendations.

3. Ask Copilot to create a new worksheet containing only the **High** and **Medium** priority recommendations.

   Example prompt:

   ```text
   Create a new worksheet containing only the High and Medium priority recommendations from the previous analysis.
   ```

4. Review the recommendations worksheet.

   ![](../media/ms4004-l8-13.png)
